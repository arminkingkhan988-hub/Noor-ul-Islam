د Android اپلیکیشن پروژه — لومړنۍ آفلاین نسخه

څه پکې شته؟
- پښتو، عربي او انګلیسي ژبې
- د انټرنېټ پرته د کار کولو لپاره داخلي HTML پاڼه
- د اسلام د زده کړې برخې: لمونځ، اودس، غسل، تیمم، روژه، زکات، حج، دعاګانې، عقیده، سیرت او ورځني مسائل
- د موضوعاتو لټون
- د Android Studio پروژه

مهمه یادونه:
دا د کار وړ لومړنی پروټوټایپ دی، نه د خپرولو لپاره وروستی او د ټولو دیني محتواوو له پلوه بشپړ اپلیکیشن.
د قرآن کریم بشپړ متن، ژباړې، د حدیثونو اسناد، د لمانځه وختونه، قبله، او تفصیلي فقهي احکام باید له باوري سرچینو څخه ورزیات او د باوري عالم له خوا وکتل شي. په اپلیکیشن کې قصداً ناسم یا بې سرچینې دیني متن نه دی جوړ شوی.

د APK جوړولو لار:
1. په کمپیوټر کې Android Studio نصب کړئ.
2. د Android Studio له لارې د دې فولډر پروژه پرانیزئ.
3. د Gradle Sync بشپړېدو ته انتظار وباسئ.
4. له Build مېنو څخه Build APK(s) انتخاب کړئ.
5. APK به عموماً په app/build/outputs/apk/debug/app-debug.apk کې وي.

اړین:
- د دې پروژې د جوړولو لپاره انټرنېټ ته یوازې د Android Studio/Gradle لومړي build پر مهال اړتیا کېدای شي.
- د نصب شوي اپلیکیشن اصلي محتوا له انټرنېټ پرته خلاصیږي.
- په موبایل کې د APK د مستقیم جوړولو لپاره عموماً Android Studio لرونکی کمپیوټر اسانه لاره ده.
